# Third-party notices and release checklist

The renderer uses React, React DOM, Radix UI, Lucide, class-variance-authority,
clsx, tailwind-merge, Tailwind CSS and shadcn-style UI component source.
The build uses Electron, electron-builder, NSIS, Vite and PostCSS tooling.
Retain and review their licenses and transitive dependency notices from the
installed npm packages before distributing a binary. Electron packages include
Chromium/Electron license material; do not remove that material from a release.

UI component references: https://ui.shadcn.com and https://github.com/shadcn-ui/ui
React: https://github.com/facebook/react
Radix: https://github.com/radix-ui/primitives
Lucide: https://github.com/lucide-icons/lucide
Electron: https://github.com/electron/electron

This source bundle was assembled without downloading npm dependencies.
A dependency lockfile, SBOM and complete generated third-party license inventory
are not included. Generate and review these after installing dependencies.

Game names are used to identify catalog entries only. No game artwork, game
binaries, publisher credentials or official publisher affiliation is bundled.
The hero illustration and application icon were created for ARSES.
