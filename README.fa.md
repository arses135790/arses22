# ARSES Desktop

سورس ویندوزی ARSES همراه با پوستهٔ Electron و تنظیمات ساخت نصب‌کنندهٔ NSIS.
این فایل ZIP نصب‌کننده نیست و هیچ فایل اجرایی بازی همراه آن نیست.

## ساخت نصب‌کننده روی ویندوز

۱. از https://nodejs.org نسخهٔ LTS با شمارهٔ 22.12 یا بالاتر و npm را نصب کن.
۲. ZIP را در پوشه‌ای مانند `C:\ARSES` از حالت فشرده خارج کن.
۳. فایل `BUILD-WINDOWS.cmd` را اجرا کن. برای دریافت وابستگی‌ها، Electron و ابزارهای NSIS اینترنت لازم است.
۴. اگر ساخت با موفقیت تمام شود، فایل `release\ARSES-Setup-1.0.0-x64.exe` ساخته می‌شود.
۵. فایل Setup را اجرا کن؛ پوشهٔ نصب قابل انتخاب است و میانبر دسکتاپ و منوی Start ساخته می‌شود.

دستورهای معادل در PowerShell یا Command Prompt:

```sh
npm install
npm run dist:win
```

ساخت برای Windows x64 است؛ نصب به‌صورت پیش‌فرض برای کاربر فعلی انجام می‌شود.
هدف پیشنهادی Windows 11 x64 است. سازگاری نسخهٔ Electron دریافت‌شده با نسخهٔ ویندوزت را بررسی کن.

## اجرای توسعه و تغییر ظاهر

```sh
npm install
npm start
```

`npm start` از رابط آمادهٔ موجود در بسته استفاده می‌کند؛ اینترنت فقط در مرحلهٔ دریافت وابستگی‌ها لازم است.
برای تغییر ظاهر، فایل‌های `renderer/src/App.jsx` و `renderer/src/style.css` را ویرایش کن.
بعد از ویرایش سورس React، این دستور را بزن:

```sh
npm run dist:win:from-source
```

تفاوت مهم: `dist:win` از رابط آمادهٔ بسته استفاده می‌کند، ولی `dist:win:from-source` تغییرات سورس React را هم دوباره می‌سازد.
اگر فقط می‌خواهی تغییرات را بدون ساخت نصب‌کننده ببینی:

```sh
npm run build:ui
npx electron .
```

دوباره اجرای `npm start` رابط آمادهٔ اولیه را جایگزین رابط ساخته‌شده می‌کند.

## قابلیت‌ها

رابط فارسی با تم تیره و نارنجی، کاتالوگ ۸۱ عنوان، جست‌وجو، فیلتر Call of Duty و Co-op، ذخیره در کتابخانه، افزودن عنوان شخصی، چک‌لیست دستی و تنظیم کاهش حرکت.
کاتالوگ نمونه است؛ شامل همهٔ بازی‌ها نیست و وضعیت سرورها و پلتفرم هر نسخه تأیید زنده نشده است.

پنجرهٔ مستقل ویندوز با آیکون اختصاصی، کنترل‌های بومی کوچک‌کردن و بستن، یک نمونهٔ هم‌زمان، بزرگ‌نمایی و نصب‌کنندهٔ قابل پیکربندی.

کتابخانه در فضای محلی برنامه زیر `%APPDATA%\ARSES` ذخیره می‌شود؛ با کتابخانهٔ نسخهٔ وب همگام نمی‌شود.
حذف عنوان از کتابخانه فقط نشان ذخیره‌شده را برمی‌دارد؛ فایل بازی یا عنوان شخصی از دیسک حذف نمی‌شود.
حذف برنامه به‌صورت پیش‌فرض داده‌های کاربر را پاک نمی‌کند. پاک‌کردن دستی آن پوشه داده‌های کتابخانه را از بین می‌برد.

## مرزهای این نسخه

این برنامه بازی را دانلود، نصب یا اجرا نمی‌کند؛ فیکس آنلاین، کرک، بای‌پس، وضعیت زندهٔ سرورها، ورود به حساب و به‌روزرسانی خودکار ندارد.
رابط داخل پوستهٔ واقعی دسکتاپ قرار گرفته است؛ این به معنی پیاده‌سازی یک لانچر کامل نیست.
ارتباط شبکه در زمان اجرا مسدود شده و فونت‌های سیستم جایگزین فونت‌های اینترنتی هستند؛ بنابراین نوشته‌ها کمی با پیش‌نمایش وب فرق دارند.

## وضعیت آزمون و انتشار

نحو فایل‌های اجرایی و آزمون‌های ایستای پیکربندی در محیط ساخت این بسته بررسی شده‌اند.
Electron و npm در محیط آماده‌سازی نصب نبودند و امکان دریافت اینترنتی وابستگی‌ها وجود نداشت؛ اجرای واقعی Electron، بازسازی سورس React، ساخت NSIS، نصب و حذف روی ویندوز آزموده نشده‌اند.
پس این بسته «سورس آمادهٔ ساخت» است، نه خروجی نصب‌شده یا ساخت تأییدشده.

Electron با مقدار `latest` دریافت می‌شود تا از نسخهٔ کهنهٔ ثابت استفاده نشود. بعد از اولین `npm install` فایل `package-lock.json` ساخته می‌شود؛ آن را نگه دار و برای ساخت تکرارپذیر بعدی `npm ci` اجرا کن.
پیش از انتشار عمومی، نسخه‌های وابستگی و هشدارهای `npm audit` را بررسی کن.
بسته گواهی امضای دیجیتال ندارد؛ خروجی بدون گواهی معتبر ممکن است هشدار SmartScreen یا ناشر ناشناخته بدهد. هشدار امنیتی را کورکورانه دور نزن؛ برای انتشار عمومی گواهی معتبر تهیه و تنظیمات امضای electron-builder را انجام بده.

## فایل‌ها

`electron/main.cjs`: پوستهٔ دسکتاپ و محدودیت‌های امنیتی.
`renderer/src/`: سورس قابل ویرایش React و تصویر اختصاصی.
`renderer/ui/`: اجزای رابط کاربری.
`renderer/prebuilt/index.html`: خروجی آمادهٔ رابط.
`scripts/prepare-renderer.mjs`: آماده‌سازی رابط محلی و سیاست امنیتی.
`package.json`: وابستگی‌ها و تنظیمات نصب‌کننده.
`tests/`: آزمون‌های ایستا، بدون نیاز به دریافت وابستگی.

نام‌ها و علائم بازی‌ها متعلق به صاحبان آن‌ها هستند؛ ARSES وابسته به ناشران یا Project Lightning نیست.

## ساخت رایگان آنلاین بدون نصب ابزار روی لپ‌تاپ

ساده‌ترین گزینه **GitHub Actions** است و کد ساخت آن در `.github/workflows/build-windows.yml` قرار دارد. این سرویس برای مخزن عمومی معمولاً رایگان است؛ برای مخزن خصوصی به سهمیهٔ حساب GitHub وابسته است.

۱. در https://github.com یک حساب بساز و یک Repository جدید بساز؛ برای رایگان‌بودن، آن را Public انتخاب کن.
۲. همهٔ فایل‌های همین بسته را داخل Repository آپلود کن. پوشهٔ `.github/workflows` را هم حتماً نگه دار.
۳. به تب **Actions** برو و workflow با نام **Build ARSES Windows installer** را باز کن.
۴. روی **Run workflow** و بعد **Run workflow** بزن.
۵. بعد از سبزشدن کار، همان صفحه را پایین برو و از بخش **Artifacts** فایل `ARSES-Windows-installer` را دانلود کن؛ داخل ZIP، فایل `ARSES-Setup-1.0.0-x64.exe` است.

راه ساده‌تر برای ساخت نسخه‌های مشخص: یک Tag مثل `v1.0.0` بساز و Push کن؛ workflow خودکار اجرا می‌شود. GitHub Actions فایل Setup را در Artifact می‌گذارد، نه در یک لینک عمومی دائمی؛ Artifact بعد از ۷ روز منقضی می‌شود.

اگر نمی‌خواهی کدت عمومی باشد، Repository را Private کن و قبل از اجرا سهمیهٔ رایگان Actions حساب GitHub را بررسی کن. رمز، API key یا اطلاعات حساب بازی را هرگز داخل Repository یا Workflow نگذار.
